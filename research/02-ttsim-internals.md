# Research: ttsim internals (ttsim b3620244, v1.15.0; tt-metal 7aad8aac; UMD 1507ff75)

Citations are `path:line` in the ttsim repo unless prefixed.

## Five facts that shape the series
1. **No runtime knobs.** No getenv calls, no trace or log flags ("The library reads no environment variables", docs/libttsim_api.md). To observe execution: edit the source plus `ttsim_printf`, or use a debug build plus gdb `break ttsim_error`.
2. **Functional model, not a timing model.** NoC transfers complete instantly. A tile is re-clocked while Tensix instructions keep succeeding (libttsim.cpp:252-283), so Tensix work costs almost no `g_clock`. Cycles are not silicon performance.
3. **"Tile" in ttsim means a NoC node** (T, E, A, P, plus D for DRAM channels), not a 32×32 data tile.
4. **Circular buffers do not exist in the simulator.** They are tt-metal software (L1 plus pointers), so CB misuse is not detected.
5. **Errors are fatal.** `ttsim_error` prints `[g_clock] ERROR: <Category>: <func>: <msg>`, then `_Exit(1)` (common.cpp:33-45). There are no warnings and no suppression.

## Chip state
- `ChipState` (sim.h:576-585) holds `t_tiles[]`, `e_tiles[]`, `a_tile`, `p_tile`, `dram[]` and a busy bitmask.
- **TensixTile** (sim.h:341-400):
  - 5 RV32 harts. IDs: BRISC=0, TRISC0-2=1-3, NCRISC=4 (config.h:124-129).
  - `TensixState`.
  - `sram`: L1 is 1464 KiB on WH and 1536 KiB on BH (config.h:135,172).
- **Grids.** WH: 10x12, 80 Tensix, 16 Ethernet tiles. BH: 17x12, 140 Tensix, 14 Ethernet tiles (sim.h:73-85).
- **DRAM.** WH: 6 x 2 GiB. BH: 8 x 4080 MiB. Mapped `MAP_PRIVATE|MAP_NORESERVE` (sim.cpp:37).
- **Ethernet send** = `memcpy` into the peer tile's SRAM (tile.cpp:2028-2033). Topologies are listed in topology.h:349-506.
- **ARC** is emulated in C++ (tile.cpp:2547-2640). Mock Ethernet firmware: fw/eth/eth_fw.c.

## Clock loop (libttsim.cpp:244-314)
- **Host-driven.** Each call to `libttsim_clock(n)` steps every chip, then `g_clock++`.
- **Busy tiles only.** Only busy Tensix tiles are visited, in ascending ID order. Each active hart runs one `rv32_step` per clock.
- **Tensix repeat loop.** The MOP/replay frontend runs, then each pipe executes its FIFO head. The tile is clocked again while any instruction succeeds.
- **Ethernet:** 16 steps per clock while busy.
- **PAUSE** parks a core until the next multiple of 256.
- **Stalls are replays.** A handler returns false, or a load rewinds `pc -= 4` (riscv_impl.h:731).
- **Deterministic.** Single-threaded with a fixed visiting order. `WALL_CLOCK` = `g_clock` (tile.cpp:1034). `FpEnvGuard` (libttsim.cpp:13-67).
- **Who drives the clock:**
  - UMD: +1 clock after every device read (`after_read`, tt_sim_tt_device.cpp:334-338).
  - riscv64: 256 clocks per BAR read.
  - qemu: a virtual timer, 1000 clocks every 100 µs.
- **At exit** it prints `[g_clock] X seconds (Y MHz)` (sim.cpp:98-106).

## RISC-V interpreter (riscv_impl.h)
- **Build.** `#define XLEN 32` plus `#include`. Decode table generated by riscv_gen_decode.py: 256 entries indexed by opcode[6:2]|funct3<<5.
- **Tensix instructions.** A word whose low 2 bits are not `11` is a Tensix instruction: `tensix_inst = (inst<<30)|(inst>>2)` (:1480), pushed to the FIFO with replay on full (:1461-1485).
- **Memory accesses:**
  - Misaligned is NonContractualBehavior (:637).
  - Then L1, then local memory at 0xFFB00000, then MMIO.
  - Caches are not modeled.
- **WH restrictions:**
  - FP is UB "Wormhole does not support Zfh/F/D/Q" (:455).
  - Atomics are UB.
  - `fence` is Unsupported (:1084). `PAUSE` is OK.
- **BH float** uses `sfpu_mad`, which is not IEEE (:480,506).
- **Speed:** the README claims more than 200 MIPS (not measured).

## Tensix coprocessor (sim.h:227-324, tensix.cpp)
- **State:**
  - 3 pipes with 512-entry FIFOs (sim value).
  - MOP config; `replay_buf[3][32]`.
  - `src_a/src_b[2][64][16]` (19-bit values in uint32).
  - `dst[1024][16]` uint16 plus `dst_row_valid`.
  - `l_regs[16][32]`; `sem[8]`; 2 config banks.
- **Push path.** `tensix_push_inst` (:295-308) routes MOP to `mop_ingest`, MOP_CFG to `mop_cfg`, and everything else to `replay_expander`. NOPs are dropped; at most 52 entries are queued (:284-293).
- **Sync between RISC-V and Tensix (PC_BUF):**
  - Reading TENSIX_SYNC stalls until the thread is idle.
  - Reading or writing SEMAPHORE(n): a write of 1 decrements, 0 increments. Underflow, or overflow past 15, is NonContractualBehavior (tile.cpp:1890-1946).
  - SEMINIT/SEMPOST/SEMGET/SEMWAIT at tensix.cpp:5516-5589.
  - STALLWAIT only really waits on Src valid (:5447-5514).
- **UNPACR** (:3153):
  - Stalls while the target bank is valid (:3170).
  - Format mismatch is UB (:3207-3212).
  - `bfp8_to_bf16` at :3141.
- **MVMUL** (`tensix_matmul_op` :1754-1921; `mvmul` :1669-1741):
  - Dst 8 rows x 16 columns; each element is a 16-term dot product.
  - Fidelity slicing:
    ```cpp
    if (fidelity_phase & 1) { man_a = (man_a >> 1) & 31; } else { man_a >>= 6; }   // 5 bits of A
    if (fidelity_phase & 2) { man_b = (man_b & 15) << 3; } else { man_b >>= 4; }   // 7 bits of B
    ```
  - Products are aligned to the max exponent in groups of 8, then accumulated (`fpu_accum_normalize_encode` :1491).
- **ELW ops** at :1944ff. **GMPOOL/GAPOOL**, MOV*, ZEROACC, SETRWC.
- **Dst:**
  - FP32 is split across two rows 8 apart.
  - BF16 is stored with exponent and mantissa swapped (`dst_encode_bf16`, :912-922).
  - Reading an invalid row returns 0, not an error.
- **SFPU:**
  - 32 lanes.
  - `sfpu_mul` and `sfpu_add` use host float plus fixups (:4165-4230).
  - `sfpu_mad` is an integer reimplementation (:4232-4331), including the WH tie quirk at :4318.
  - SFPLOADMACRO is Unsupported (:5138), so set `TT_METAL_DISABLE_SFPLOADMACRO=1`.
- **PACR** (:2343): the only UnpredictableValue check is "bfp exponents past Exp_section_size" (:2682).
- **Bit-exactness comes from:**
  - integer datapaths;
  - host float only where it is exact;
  - `-ffp-contract=off`;
  - a forced FP environment;
  - explicit encode and decode;
  - per-architecture quirks.
- **ISA JSON:**
  - `tensix_isa.json`: WH has 128 opcodes (36 unsupported). Example: `"MVMUL": {"opcode":38,"args":{"dst":"9:0",...}}`.
  - `tensix_gen_decode.py` raises UB "invalid opcode bits set" when reserved bits are used.
  - `tensix_regs.json` generates bitfield unions plus unsupported-field checks.
  - `tile_regs.json` is the address map. Key windows:

    | Window | Address |
    |---|---|
    | local_mem | 0xFFB00000 |
    | debug_regs | 0xFFB12000 |
    | noc0 | 0xFFB20000 |
    | mop_cfg | 0xFFB80000 |
    | regfile | 0xFFE00000 |
    | tensix_inst | 0xFFE40000 |

  - The `perf_cnt_*` registers are unsupported.

## NoC, L1 and DRAM
- **`noc_cmd_ctrl`** (tile.cpp:1397-1623) validates, translates coordinates (`remap_virtual_coordinate` :1147), then transfers immediately and updates counters synchronously. So barriers always pass, and a missing barrier is hidden.
- **Multicast** skips harvested rows; Tensix destinations only (:1468-1525).
- **Atomics:** increment only.
- **Alignment rules:**
  - Write: `(src&15)==(dst&15)`, or UB (:1589).
  - Read from DRAM: 32 B (WH) / 64 B (BH); L1 to L1: 16 B (:1605-1619).
- **No contention or deadlock modeling.**
- **L1** is a flat array with no banks.
- **Reset PCs** (tile.cpp:1096-1127, set through SOFT_RESET_0):

  | Core | Reset PC |
  |---|---|
  | BRISC | 0 |
  | TRISC0 | 0x6000 |
  | TRISC1 | 0xA000 |
  | TRISC2 | 0xE000 |
  | NCRISC | 0x12000 |

  Each can be overridden.

## libttsim API (10 symbols)
- `libttsim_init` (second call is a ConfigurationError) and `libttsim_exit`.
- `set_pci_dma_mem_callbacks` (must be called before init).
- `pci_config_rd32/wr32`: vendor 0x1E52, device 0x401E (WH) or 0xB140 (BH).
- `pci_mem_rd_bytes/wr_bytes`: BAR0 is TLB windows into the NoC (WH: 156x1M + 10x2M + 20x16M; TLB config at BAR0+0x1FC00000).
- `libttsim_clock(n)`.
- `tile_rd/wr_bytes`: Unsupported on WH/BH.
- **UMD loader:** `tt_sim_communicator.cpp:755-770` does `dlopen` plus a memfd copy. `tt_sim_tt_device.cpp:150-200` handles bring-up. Reset is a read-modify-write of soft reset (:378-416).
- **tt-metal side:** `rtoptions.cpp:523-527` reads `TT_METAL_SIMULATOR`.

## Error taxonomy (common.h:16-52) with examples
- **UB:**
  - bad RV instruction (:1490);
  - Tensix reserved bits;
  - nested REPLAY (tensix.cpp:65);
  - Src bank races (:762,769), e.g. "move into Src%c bank %d before waiting for it, which an unpacker wrote";
  - unpack format mismatch;
  - NoC alignment;
  - DRAM overrun.
- **NonContractualBehavior:**
  - misaligned RV load;
  - clear of a Src valid bit that is not set (:778);
  - SEMPOST past max (:5538);
  - SEMGET on 0 (:5551);
  - MMIO semaphore underflow (tile.cpp:1934).
- **UnpredictableValue:** only the BFP pack exponent check (:2682).
- **Unsupported:** SFPLOADMACRO, WH fence, compressed unpack, perf counters.
- **Unimplemented:** e.g. ecall, byte-enable NoC.
- **ConfigurationError / SystemError; AssertionFailure.**
- **Not caught:** CB over-push, missing barriers. Reading never-written Dst returns 0.
- **Recommended test pattern:** fork per test (docs/sim_error_handling.md).
